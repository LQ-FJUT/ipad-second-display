# 第三方组件与安装边界

iPad互联的 Windows 发送端基于 OpenDisplay 生态的开源实现开发。本文档说明发布物中包含的源码、只在用户电脑上作为前置条件存在的组件，以及安装器明确不会执行的操作。

## 不随安装包分发的组件

### Parsec Virtual Display Driver

Parsec VDD 驱动二进制文件不属于上述头文件的许可范围，不包含在 iPad互联安装包或源码压缩包中。如选择“由程序创建 Parsec 虚拟显示器”模式，用户需要从经确认的官方来源单独安装兼容且已签名的驱动。当前批准的独立包为 Microsoft WinGet 清单中的 `Parsec.ParsecVDD` `0.45.0.0`，官方 CDN 文件 SHA-256 为 `E23332448FDAF5AA017CB308DB5EF6855FAC526A7DED05D80C039404126D5362`，许可元数据为 `Proprietary`。

Parsec 官方把 VDD 定位为 Parsec 会话组件；MouseLink 通过社区头文件直接
调用其 IOCTL 属于厂商未明确支持的集成。首次验收必须保留安装前报告与
安装后收据，并准备精确回滚。当前官方安装说明没有要求手工运行
`vddinstall.bat`，因此工程不会自动执行该批处理、`nefconw` 或另一条驱动
安装路径。

iPad互联安装器不会：

- 下载、安装、更新、禁用或卸载 Parsec VDD。
- 下载、安装、更新、禁用或卸载 GameViewer Virtual Display Adapter。
- 调用 `pnputil`、`devcon`、`nefconw` 或任何驱动安装脚本。
- 启用 Windows 测试签名模式。

卸载 iPad互联时，上述驱动及其他虚拟显示器均保持不变。

### OpenDisplay iPad/iPhone 接收端

iPad/iPhone 端应用不包含在 Windows 安装包中。用户应通过 OpenDisplay
项目 README 公布的公开 TestFlight 独立获取；若 TestFlight 不可用，则需
按上游说明用 Xcode 自行签名。Windows 端仅使用其公开的 TCP/H.264 协议
进行连接。

## Windows 系统组件

程序使用 Windows SDK 提供的 DXGI、D3D11、Media Foundation、Winsock、SetupAPI 和其他系统 API。这些系统组件不随本工程重新分发。Windows 端使用静态 MSVC CRT 构建，安装包不需要另外安装 VC++ Redistributable。

## 安装器与网络边界

- 默认安装位置为当前用户的 `%LOCALAPPDATA%\Programs\iPad互联`，不需要管理员权限。
- 桌面快捷方式为可选项。
- 不创建 Windows 服务、计划任务或开机/登录自启动项。
- 不添加、修改或删除防火墙规则。
- OpenDisplay 协议 v3 本身不提供 TLS 或身份认证，因此当前版本只能在用户信任的私有局域网中使用，不应进行公网端口转发。

## 构建工具

发布脚本可调用 Inno Setup 6 生成安装包。Inno Setup 是构建工具，不会被安装到用户的电脑上。详见 [Inno Setup 官方站点](https://jrsoftware.org/isinfo.php)。
