# 驱动安全与回滚

本工程把 `GameViewer Virtual Display Adapter` 视为受保护资产。安全脚本不会安装驱动、修改网络、禁用设备或自动调用第三方卸载器；除实际回滚脚本带 `-Apply` 外，所有脚本只读取系统状态并把 JSON 证据写入工程的 `reports\safety`。

## 固定保护基线

安装 Parsec VDD 前必须同时满足：

- 设备实例：`ROOT\DISPLAY\0000`
- 发布 INF：`oem117.inf`
- 驱动版本：`15.6.5.199`
- 提供者：`GameViewer`
- 活动版本 `GameViewerIddDriver.dll` SHA-256：`5C584EA95474957983C0AE0862D2C1844D558D78B4B2C7C7A9AD704092240A5E`
- 用于 iPad 传输的活动网络：`Private`
- 系统中没有任何现有 Parsec 设备、签名驱动记录或卸载记录
- 待运行安装器为 WinGet 清单固定的 `Parsec.ParsecVDD` `0.45.0.0`，实际
  SHA-256 为 `E23332448FDAF5AA017CB308DB5EF6855FAC526A7DED05D80C039404126D5362`
- 安装器 Authenticode 必须为 `Valid`，签名人及证书指纹必须与批准文件一致

若 DLL 路径改变，但版本和哈希仍可信，可用 `-GameViewerDllPath` 传入经过人工核对的精确文件路径。不得为了让检查通过而随意覆盖期望哈希。

## 安装前门禁

在普通 PowerShell 中执行：

```powershell
$project = (Resolve-Path '.').Path
$driverInstaller = "$project\.tools\drivers\parsec-vdd-0.45.0.0.exe"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$project\tools\safety\Test-PreInstallSafety.ps1" -NetworkInterfaceAlias 'WLAN 2' -DriverInstallerPath $driverInstaller
```

返回码：`0` 表示全部通过，`2` 表示门禁未通过，`3` 表示脚本异常。无论通过与否，报告都会写入 `reports\safety\pre-install-safety-*.json`。

当前实机的 `WLAN 2` 曾被检测为 `Public`，因此门禁会按设计失败。确认这是可信私人局域网后，网络类别必须由用户单独、明确地修改，例如在管理员 PowerShell 中执行：

```powershell
Set-NetConnectionProfile -InterfaceAlias 'WLAN 2' -NetworkCategory Private
```

安全脚本绝不会代替用户执行这项修改。修改后重新运行安装前门禁，以新生成且 `OverallPass: true` 的报告为准。

安装器来自 Parsec Cloud Inc.，许可为专有软件，不属于本工程的 GPL/BSD
许可。用户确认接受厂商条款后，首次验收只交互运行上述已批准安装器。
当前 Parsec 官方说明未要求额外执行 `vddinstall.bat`；不得自动运行该批处理、
`nefconw` 或另一条安装路径。若安装结束后不存在精确的
`Root\Parsec\VDA` 设备，立即停止并保存证据。

## 安装后生成唯一收据

交互安装批准的 Parsec VDD `0.45.0.0` 后，立即生成收据。必须显式指定
刚才通过的安装前报告，不能使用目录通配符：

```powershell
$project = (Resolve-Path '.').Path
$baseline = Join-Path $project 'reports\safety\pre-install-safety-具体时间与编号.json'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$project\tools\safety\New-PostInstallReceipt.ps1" -PreInstallReportPath $baseline
```

脚本重新核验安装器未变、GameViewer、Private 网络和 Parsec 身份，并强制
驱动 `IsSigned=True`、`Signer` 非空。全部通过后生成：

- `driver-install-receipt-<UTC 时间>-<唯一编号>.json`
- 与其精确同名的 `.json.sha256` 完整性文件

收据记录批准安装器的来源、哈希和 Authenticode 身份，以及本次确认到的
Parsec 设备实例 ID、`oem<数字>.inf`、签名人和版本。未写入收据的设备、
INF、文件或注册表项永远不属于自动回滚范围。

## 精确回滚

先在主面板中断开所有 iPad 并退出 iPad互联，同时关闭其他使用 Parsec
虚拟显示器的会话。预演会枚举当前活动的 `DISPLAY\PSCCDD0\*`
监视器；只要仍有一个活动输出，就会拒绝批准回滚，避免中断其他应用的屏幕。

先在普通 PowerShell 中进行只读预演：

```powershell
$project = (Resolve-Path '.').Path
$receipt = Join-Path $project 'reports\safety\driver-install-receipt-具体时间与编号.json'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$project\tools\safety\Invoke-ReceiptRollback.ps1" -ReceiptPath $receipt
```

预演会验证收据 SHA-256、机器名、GameViewer 完整性、每个设备的精确硬件 ID，以及每个 INF 当前仍属于收据中的 Parsec 驱动。只有预演 `OverallPass: true` 时，才在管理员 PowerShell 中明确加入 `-Apply`：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$project\tools\safety\Invoke-ReceiptRollback.ps1" -ReceiptPath $receipt -Apply
```

实际动作严格限定为：

1. `pnputil /remove-device <收据中的精确实例 ID>`
2. 再次证明该 INF 已无任何设备使用，然后执行
   `pnputil /delete-driver <收据中的精确 oemN.inf>`（不使用 `/uninstall`）

脚本不使用 `/force`、`-Force`、通配符、名称批量匹配或目录递归删除。只要 GameViewer 基线漂移、收据被修改、目标身份无法重新证明，回滚就会拒绝执行。

厂商卸载器和 `Program Files` 中的解压文件不在自动回滚范围，因为第三方卸载器内部动作无法由收据逐项约束。需要清理时，应先保存回滚报告，再人工核对官方卸载入口；不得删除 `oem117.inf` 或 `ROOT\DISPLAY\0000`。

## 报告保留

验收结束前不要删除以下证据：

- 安装前门禁报告
- 安装收据及其 `.sha256`
- 回滚预演/执行报告
- 实机验收报告

这些文件都在工程 `reports\safety` 下，便于比较安装前后状态，不会写入用户其他项目目录。
